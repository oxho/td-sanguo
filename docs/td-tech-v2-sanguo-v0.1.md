## 2. 整体架构与目录

原则（沿用并收紧旧稿，已按三国题材替换名词）：
- **逻辑与渲染分离**：`core/` 不引用 Phaser、DOM、Storage、`Date`、`Math.random`。输入是命令，输出是状态 + 事件。
- **格单位**：模拟内射程、速度、半径一律用格（浮点）；`逻辑像素 = 格 × 60`。设计分辨率 720×1280；地图区 540×960（9×16）；顶栏 80、波次栏 72、操作栏 168。缩放用 Phaser `Scale.EXPAND`（720×1280 安全画框完整可见，长屏上下延伸、宽屏左右延伸）。
- **判定**：射程/溅射/光环用格单位欧氏距离，塔在塔基格心，敌人沿路径插值，不吸附到格心。
- **固定步长**：逻辑 30 Hz，渲染插值；后台暂停并清空累加器。
- **确定性**：唯一 RNG 为带种子的 PRNG；状态可序列化。
- **固定塔基、固定路径，无动态寻路**（已确认）：关卡表给塔基 `{id,col,row}` 和路径折线；敌人只存 `pathId + progress`。飞行（斥候鹰）走入口到城门的直线路径。英雄下令驻守时在可走格上做一次 BFS。
- **数据驱动**：数值在 `data/*.json`，启动时 schema 校验；关卡波次 **直接读取** `td-sanguo-levels.json`（或构建时拷入 `data/levels/`），不以手写表覆盖 JSON。
- **对象池、存档抽象、平台适配层**：同旧稿。V0.1 平台实现只有 `web/`。

建议仓库目录（经理建仓后采用）：
```
td-sanguo/
  package.json  vite.config.ts  tsconfig.json  capacitor.config.ts  # capacitor 仅预留
  src/
    core/
      sim/        # World、tick、命令、事件、快照
      systems/    # 出怪/路径/索敌/伤害(克制·护甲·护盾)/状态/子弹
                  # 枪兵阻挡/英雄/谋略卡/分支技能/经济/波次/军令军约/精英/Boss
      rules/ meta/ rng.ts pool.ts units.ts
    data/         # 塔、分支、敌人、谋略卡、武将、羁绊、抽卡、军令军约、i18n/zh-CN
                  # levels/ 来自 td-sanguo-levels.json；maps/M1.json M1b.json（格坐标）
    render/       # Phaser 场景：Boot Preload Menu LevelSelect Prepare Battle Gacha Result
    ui/
    platform/     web/  capacitor/   # capacitor 为空实现
    services/     # 本地桩，V0.1 不发网络请求
    app.ts  main.ts
  assets-src/  public/assets/  tools/  tests/
  THIRD_PARTY_NOTICES.md
```

客户端模块边界：
| 层 | 允许依赖 | 禁止 |
|---|---|---|
| `core/` | 自身 + 已校验的数据对象 | Phaser、DOM、存储、时间 API |
| `data/` | JSON + schema | 游戏逻辑 |
| `render/` / `ui/` | core 的只读状态和事件、Phaser | 改写模拟（只能发命令） |
| `platform/` | 浏览器 API | 游戏规则 |
| 场景 | 组装上面四层 | 把数值写死在场景里 |

`td-sanguo-levels.json` 的 `rules`（东风、Boss 系数、双入口）V0.1 要实现 **Boss 预告系数 ×0.6**；东风和双入口本范围关卡为 false，逻辑可后置，但不要写与 JSON 相反的硬编码。

## 3. 存档方案（无服务端，已确认）

两份存档，均在浏览器本地，带版本号、`dataHash`、校验和；双槽轮流写。

**meta 存档 `td.meta`**（`localStorage`，必要时升 IndexedDB）：虎符、已拥有武将、保底计数与十连相关状态、1-1～1-5 通关与星级、已解锁塔/谋略卡/卡槽、设置、引导进度、图鉴已见；预留字段：后续关卡、每日挑战日期、无尽最高波、1-5 通关后的每日挑战解锁标记（入口仍隐藏）。

**局内快照 `td.run`**：结构沿用旧稿 7.4，字段改成军资、城门、谋略卡冷却、军令/军约、精英词缀、预告 Boss 状态。不存纯表现。

写入时机：每波开始（波前检查点）、波中每 5 秒、切后台/`visibilitychange`/`pagehide`、打开面板或暂停时；胜负或放弃后删除。

恢复：【临时默认，非已定，对应 15.3 第 5 项】恢复到中断时刻并进入暂停，由玩家点继续；波前检查点仅在快照损坏或数据表不兼容时兜底。确认前不作为验收。被系统杀进程后，启动时弹“继续上局 / 放弃”。

导出导入：设置页导出文本，导入前提示覆盖；格式错误不破坏原存档。

抽卡：本地带种子的 PRNG；规则按 PRD 7.4（75/21/4、30 抽传说保底、十连前 9 抽全稀有则第 10 抽按 21:4 在史诗/传说中取，传说也算满足“至少 1 史诗”；十连每一抽计入传说保底）。公示两组概率（基础 75/21/4，全部十连综合 73.28/21.02/5.70），改规则必须重跑 `sanguo-gen/gacha_rates.py`。全程无付费入口、无付费 SDK。

## 4. V0.1 必做 / 不做清单

### 必做
1. 主界面、章节选关（只亮第一章 1-1～1-5；其余节点锁定）、关卡详情、出战准备（2 武将 + 最多 2 张谋略卡）、战斗 HUD、暂停/设置、结算（三星逐条）、抽卡（单抽、十连结果、概率公示）、武将详情（可简）。
2. 战斗循环：固定塔基建塔、射程预览确认、升级/卖塔、1-4 起 Lv4 分支选择与分支技能、开波与 15 秒倒计时、清波军资、提前开波奖励、城门生命与升级、漏怪扣血、胜负。
3. 按 JSON 出怪；出生间隔 0.8 秒，一波内按表中顺序轮流；1-5 每波第 4、8、12… 个为精英，词缀在坚韧/迅捷间轮流；1-5 第 10 波最后出乱军都尉（生命/护盾上限 ×0.6，打完或到达城门，不撤退，不进阶段 2）。
4. 兵种克制、护盾（刀盾兵）、闪避（山贼第一次受伤）、飞行直线（斥候鹰：投石车/拒马阵/枪兵不能选为目标，不受地面效果）、轻骑冲刺。伤害结算按 PRD 4.1–4.2。
5. 谋略卡火攻、万箭齐发：指定范围，预览取消或未命中不进冷却。
6. 武将上阵、驻守、主动技、被动、羁绊；倒地 20 秒在城门旁复活。
7. 军令、军约（第 3、6、9 波后出军令，波前可选军约；1-1 起就会碰到）。
8. 1-1 强制引导（建箭楼 → 开波 → 升级 → 放火攻），可跳过；1-3 讲第二卡槽；1-4 讲分支。
9. 本地 meta + 局内快照 + 导出导入。
10. 简体中文。调试面板：读塔伤/射程/攻速、当前伤害公式、波次日志（用于对照 JSON）。

### 不做（V0.1）
第 2–3 章与 1-6+ 的敌人/塔/卡/地图（床弩、火油台、烽火台、伏兵、冲车、东风、双入口、水战、三个完整阶段 Boss、无尽、每日挑战页）；账号与任何网络服务；iOS/Android 包；托管与商店上架；广告。

星级按 PRD：1 星通关，2 星城门生命 ≥50%，3 星再加本关专属（1-1/1-2/1-4 不漏怪，1-3 城门没被漏怪扣血，1-5 建塔不超过 10 座）。1-5「建塔不超过 10 座」在 PRD 未写清卖后再建是否计入，V0.1 **按本关内曾经建造的座次数计入（卖了也算）**，并在结算页注明；请策划补一句。

## 6. 性能预算（V0.1 网页）

沿用旧稿指标，按本范围收紧：

| 项 | 预算 | 说明 |
|---|---|---|
| 帧率 | 中端机（iPhone 12 / 骁龙 778G）同屏 60 敌 ≥50 fps | 1-5 单波最多约 14 人 + 预告 Boss + 召唤（预告不进阶段 2，无召唤），余量充足 |
| 进入主界面 | 4G 10 Mbps、RTT 100 ms、冷缓存，P75 ≤ 5 秒 | 首包传输 ≤ 3 MB；JS gzip ≤ 600 KB |
| 进入 1-1 战斗 | 另加载 M1 包 ≤ 6 MB，同网络条件 ≤ 5 秒 | M1b 共用或镜像同一套地图资源 |
| 下载 zip | 内部目标 ≤ 40 MB（远低于 150 MB 安装包上限） | WebP 图集、AAC 音效；V0.1 可用占位图，正式图按 ui-v5 替换 |
| 图集 | 单张 ≤ 2048，常驻 ≤ 4 张（V0.1 单位少） | 合批，draw call ≤ 50 |
| 内存 | JS 堆 ≤ 150 MB | 对象池 |

音频可后置为几条占位音效 + 一轨 BGM；无视频。验证：Playwright 限速 10 Mbps 记主界面可交互时间；真机待用户提供。
