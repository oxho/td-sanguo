# V0.1.1 自测（点击区、底栏环、版本号）

日期：2026-11-26。在 `e0cff93` 上修 QA-V011-001、002、003。测的是 `npm run build` 的 `dist`，`npx serve dist`。尺寸是视口 CSS 像素（`getBoundingClientRect`），不是 720×1280 画框里的设计像素。

## 改了什么

- 可点控件的设计尺寸至少 90×90。最紧的 360×800 缩放是 0.5，90×0.5 = 45，大于 44。波次栏加高到 112，操作栏里的谋略卡宽 92、高 100，开始下一波按钮更高。
- 靠下塔基（M1-p15）的整环上移，按钮底边停在波次栏上方，左右边缘仍整环留在画框里。先预览射程，再点确认。
- 关于页改为「V0.1.1 网页竖屏试玩」。导出 `version` 仍是 1，`dataHash` 仍是 `sanguo-v0.1-2026-11-26`。

## 怎么跑

```bash
npm install
npm test
npm run build
npx serve dist
```

不要用 `file://` 打开 `index.html`。
