# V0.2 M1 自测

日期：2026-11-28。从 main 的 `5cdfe52`（已打 tag `v0.1.4`）开分支。测的是 `npm run build` 之后的 `dist`，用 `npx serve dist` 打开。战斗单位是彩色方块占位，不是正式斜俯美术。

## 改了什么

- 准备时间第 1 波 5 秒、之后 8 秒。首次 1-1 放下第一座塔才倒数。提前开战奖励仍是每秒 2，上限 14。
- 出怪改成每股 3 只，股内 0.5 秒、股间 2.5 秒。1-2 第 4 波是 4 只一股、间隔 0.3 秒。
- 敌人速度和开局军资按文档：1-1 到 1-5 是 200 / 120 / 130 / 140 / 150。生命成长读关卡字段。
- 解锁改成读塔表：1-2 军旗台，1-3 拒马阵，1-4 枪兵营。黄忠冷却 18 秒，马超 15 秒，开局就能放。
- 倍速 1× / 2× 只在这一局里记住，不写进账号存档。1-1 第 2 波起才能点。
- 缩放只在 `src/view/viewport.ts`。`#frame` 用 `transform: scale`，高屏仍留黑边。投影参数在 `src/data/view.json`（S0=72，k=0.82，Y0=150）。
- 存档升到 v2，`dataHash` 是 `sanguo-v0.2-2026-11-28`。导入 v1 会留下武将、虎符和星级，丢掉没打完的那一局。覆盖前仍要确认。

## 怎么跑

```bash
npm install
npm test
npm run build
npx serve dist
```

不要用 `file://` 打开 `index.html`。
