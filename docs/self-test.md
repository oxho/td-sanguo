# V0.1.3 自测（顶栏、波次预告、调试按钮、选关滚动）

日期：2026-11-26。在 `2fa6073` 上修 QA-V012-001 到 004。测的是 `npm run build` 的 `dist`，`npx serve dist`。点击尺寸仍是视口 CSS 像素。关于页仍写 V0.1.1。导出 `version` 仍是 1，`dataHash` 仍是 `sanguo-v0.1-2026-11-26`。

## 改了什么

- 波次标题改成顶栏中间的一块实心底，不再用会滚动的 `.grow`，木纹也不再在字中间接缝。暂停仍是 90×90。
- 「下一波」和兵种预告放在竹简上的纸签里，可以换行。军约出现后整句仍在栏内。
- 战斗画面不再放「调试」按钮。引导条挪到右上，左上塔基的「取消」和「跳过引导」互不重叠。
- 选关页中间改成一栏排开，关卡点都在一屏里，不再出现内部竖向滚动条。

## 怎么跑

```bash
npm install
npm test
npm run build
npx serve dist
```

不要用 `file://` 打开 `index.html`。
