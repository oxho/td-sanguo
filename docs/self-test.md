# V0.1.4 自测（地图画布对齐点击层）

日期：2026-11-26。在 `6ca5fad` 上修 QA-V013-001。测的是 `npm run build` 的 `dist`，`npx serve dist`。关于页仍写 V0.1.1。导出 `version` 仍是 1，`dataHash` 仍是 `sanguo-v0.1-2026-11-26`。

## 改了什么

Phaser 原先用 `Scale.EXPAND`，读的是已经被 CSS zoom 缩小后的父盒子，再把画布缩一次。桌面 1280×800（zoom 0.625）时，画布只有 281×375，而 `#hit` 是 450×600。点看得见的塔基点不中，环形菜单却画在木纹边上。

现在缩放模式改为 `NONE`，画布 CSS 固定为 720×960，和 `.map-slot` / `#hit` 一样大。外层 zoom 只缩一次，画布、点击层和环形菜单用同一套坐标。

## 怎么跑

```bash
npm install
npm test
npm run build
npx serve dist
```

不要用 `file://` 打开 `index.html`。

## 画布和点击层

视口 CSS 像素，`getBoundingClientRect`。三档都重合（误差小于 1.5）。

| 视口 | 画布与 `#hit` |
|---|---|
| 1280×800 | 415, 60，450×600 |
| 390×844 | 0, 127.3，390×520 |
| 360×800 | 0, 128，360×480 |

点看得见的 M1-p5 会打开环形菜单，确认前军资仍是 220，确认后才变成 170。M1-p15、M1-p6、M1-p0 的按钮中心都落在画布上，整环在画框内，底环在波次栏上方。
