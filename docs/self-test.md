# V0.1 自测

日期：2026-11-26。修的是 QA-V01-001、002、003。测的是 `npm run build` 之后的 `dist`，用 `npx serve dist` 打开。Chrome 无头，逻辑像素视口。

## 这次改了什么

- 点空塔基弹出环形菜单（名称和价格，买不起的置灰）。点图标后出射程圈，再点中间的「确认」才建造。取消不建造。菜单靠近屏幕边缘时整环往里收，图标仍在 720×1280 画框内，直径 68（不小于 44）。1-1 引导也走同一套，点塔基不会直接生成箭楼。
- 720×1280 画框按视口缩小，布局尺寸和看到的尺寸一致，页面不能滚动。高屏上下留空，宽屏左右留空。
- 设置里点「导入」先弹出「覆盖当前存档？」。取消不改当前进度。格式不对不弹确认，也不改当前进度。

提前开波：准备阶段按钮只在剩余整秒大于 0 时写「提前 +N」，N = 剩余整秒 × 2，并且倒计时不会减到 0 以下。本轮没有复现「提前 -8」。

## 怎么跑

```bash
npm install
npm test
npm run build
npx serve dist
```

不要用 `file://` 打开 `index.html`。

## 已知问题

- 字体仍是 Noto Serif SC 和 Ma Shan Zheng 的 OFL 子集。乱兵和多数武将仍是剪影。没有配乐。
- 枪兵接触伤害仍是需求未写的占位（每秒 8 到 14）。
- 「提前 -8」这次没有复现。公式是剩余整秒 × 2，并且不会小于 0。若再出现，需要当时的按钮截图。
