# 塔防 V0.2 美术试点：策划拍板（2026-11-28）

依据：/workspace/game-art/td-v02-pilot/（NOTES.md §3、§4，spec_luanbing_vs_shanzei.md，ref/luanbing_vs_shanzei.png，preview/M1_preview_720x1280.png），PR #2 自测截图 docs/self-test/v014-360-p15.png 和 v014-390-p15.png，以及 PRD V0.2 §3。标注说明：【策划拍板】可以直接推进；Q8 属于 V0.2 原有的待用户确认项，这里只把口径定清楚。

1. 【策划拍板】“宽 0.6 格”改为按人物可见身高定，不按帧宽，也不按身宽：s=1 时普通敌人身高 0.8 格，刀盾兵 0.95 格，Boss 1.4 格；帧继续用 128，不用改成 256，只把敌人图集 meta.td.pxPerCell 从 213.33 改为约 144（等于人物在帧内的像素高 ÷ 0.8）。PRD V0.2 §3.1 按这条改口径。
2. 【策划拍板】山贼描边用亮草绿 #B5E05A，不用暖黄：敌人走在土黄色路面上，绿描边对比更强；暖黄会和 V0.2 新加的飞金币、军资 UI 撞色。用 shader 或 postFX 外描边，不烘进帧。
3. 【策划拍板】山贼兵器用大刀（宽背弧刃），不用横刀：大刀剪影横向、短宽，和乱兵的竖直长矛区别最大；PRD V0.2 §3.1 的“横刀”改成“大刀”。
4. 【策划拍板】p15 保持 (6,15)，不移动。理由一：在 2D 自测截图（360、390 宽）里，p15 在底栏上方可见，没有被盖住。理由二：城门也在第 15 行，这一行无论如何必须完整露出。但 2.5D 全屏预览里，p15 大约在屏高 79% 的位置，而 390×844 截图里底栏从大约 77% 开始，所以布局必须把第 15 行（含城门）整行放在底栏上方，至少留 8px，这条并入验收 A14；只有布局实在做不到时才改到 (6,13)，并重出背景。
5. 【策划拍板】人物大小不够：现在身高约 0.54 格，在预览图里比塔小太多，远处一行只有十几像素，看不清。按第 1 条放大到 0.8 格，约为现在的 1.5 倍；最远一行实际约 0.6 格，在 375pt 宽的屏幕上约 25pt 高，路面宽 0.84 格，放得下。放大后请美术重出一张 preview 复核。
